# Module Documentation

This folder contains focused documentation for frontend modules that need more
detail than the general architecture notes.

## Available Module Docs

- [Visitor Management](./visitor-management.md)

## When To Add A Module Doc

Add a module doc when a feature has:

- Special routing or permissions.
- A separate API client or auth flow.
- LocalStorage or offline behavior.
- Module-specific design-system wrappers.
- Non-obvious integration points with backend services.
